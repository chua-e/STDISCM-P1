# STDISCM P1: Threaded Prime Number Search

The program creates `x` number of threads that will search for prime numbers of a given `y` number. These are configurable in `config.txt` where `x` defines the number of threads and `y` is the number range of the prime search.

There are four variants of this program:
1. Printing immediately with a straight division of search range 
2. Printing immediately with linear search as threads are used for individual number checking
3. Wait until all threads are done before printing the result of a straight division of search range 
4. Wait until all threads are done before printing the result of a linear search
